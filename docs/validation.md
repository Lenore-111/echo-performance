# Echo Performance 实机验收记录

日期：2026-10-09（Asia/Shanghai）。分支：feature/echo-performance-long-chat。状态：本地实验版，未发布 release；共创号远端仓库尚未创建。

## 环境和方法

实验基础设施：h675786161-prog/sillytavern-lab，GitHub 当前规范仓库为 h675786161-prog/lab，main commit 3c45f56ee7bc3b5742b57a9d4b54c0f950d7e01b。实际服务使用固定 SillyTavern 1.18.0 commit 8172dcd0ee672d3cd9a5e5f7af134f91a45cd2b8，独立运行目录和独立 echo-test-data；没有使用日常聊天或设置。

浏览器：Edge/Chromium 154.0.4258.62，1440×980，无头真实浏览器。另有 390×844 和 320×640 页面、真实鼠标滚轮、原生设置按钮与保存后重新加载验证。

使用合成角色 Echo Bench；每楼含 8 段 Markdown 正文，角色楼含 reasoning 和两份 swipe。通过酒馆真实角色和聊天 API 创建、打开和保存。chat_truncation=10000，全量渲染，Echo 不修改该设置。每档每种模式各三次，同一浏览器内交替开启/关闭，第二次交换顺序。

输入指标为输入事件到两个动画帧的 P95，是响应代理，不是标准 INP。滚动为 80 帧快速跨越整个聊天的 scrollTop 压力测试，其 P95 不等于物理滚轮 FPS。保存是原生 saveChatConditional 的端到端时长。长任务统计覆盖打开、稳定等待、输入、滚动及三次保存；heap 未强制 GC，不能据此声称稳定节省内存。

## 方案选择

移出正文节点的原型将 700 楼聊天 DOM 从 61250 降至约 46070，但滚动 P95 达约 359.5ms、长任务中位数约 109 次，明显失败。失败原始记录保留在 evidence/rejected-dom-only.json。该逻辑已从运行代码移除。

当前实现保留完整 DOM，按楼使用 content-visibility: auto，测量现有楼高后设置可移除的布局约束。最近 40 楼、当前视口前后 2000px，以及媒体、自定义交互等保持原样；原生事件、生成、编辑和全文操作前释放约束。没有改聊天数组、reasoning、swipes、metadata 或保存函数。DOM 总数不会下降。

## 功能与兼容性

- Echo 单独：23 项检查通过，页面异常 0。
- 世界背面组合：25 项检查通过，页面异常 0。真实插件来自 h675786161-prog/world-backstage commit f9babfa0ee0bd3003d3529fd171b83103cfee4c1；manifest 版本 2.5.8，插件当前 host 自报版本 2.5.7。保留真实面板和原生事件处理，自动模型任务、自动隐藏旧楼关闭，记忆整理设为手动。没有证明完整模型世界推演或自动隐藏组合兼容。
- 真实设置 UI：6 项检查通过，包括开启、保存后刷新恢复、暂停、继续和关闭持久化。
- 覆盖楼层编号、原节点身份、正文和 metadata 逐字不变、滚动高度误差 ≤2px、最近 40 楼、事件监听器、第三方 DOM 写入、iframe/自定义标记跳过、历史编辑与取消、swipe 来回切换、reasoning 展开、重生成、保存 JSONL 回读、浏览器查找和两个移动宽度。
- 重生成通过真实酒馆生成流程，仅模型接口回复为确定性测试数据；没有调用外部付费模型。
- 原生编辑器关闭后缩放窗口的 autocomplete 错误在 Echo 关闭时也能复现，记录在 evidence/upstream-control.json。该问题未改 SillyTavern 核心；移动页面验收在保存后刷新启动的新会话中完成。

截图已检查：正文可见，移动宽度无聊天横向溢出，世界背面真实面板可打开和关闭。尚未验证群聊、大型世界背面存档、自动隐藏旧楼、所有第三方插件、其他浏览器或真实模型流式传输。
